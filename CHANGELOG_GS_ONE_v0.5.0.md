# GS ONE v0.5.0

## Communication Engine - Flujo 1

- Captura manual de correo o WhatsApp.
- Identificación de cliente por correo o teléfono.
- Creación automática de prospecto cuando no existe.
- Clasificación de intención, marca, producto y talla.
- Creación automática de proceso comercial y tarea.
- Vinculación completa entre Inbox, cliente, análisis, proceso y tarea.
- Prevención de duplicados al reprocesar una entrada.
