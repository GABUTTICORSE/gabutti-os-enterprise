# GS ONE v0.6.7 — Instalación y prueba

1. Descomprime el ZIP.
2. Haz clic derecho en `INSTALAR_SRE.command` y elige **Abrir**.
3. Después usa `INICIAR_GS_ONE.command` para iniciar GS ONE.

## Prueba recomendada

1. Abre **Clientes > + Cliente**.
2. Ingresa un RUT nuevo y espera el autocompletado tributario.
3. Revisa **Datos de facturación**:
   - marcado: usa tributarios;
   - desmarcado: permite datos diferentes.
4. En **Datos de envío**, prueba:
   - Copiar tributarios;
   - Copiar facturación;
   - Usar datos diferentes.
5. Guarda el cliente.
6. GS ONE abrirá su ficha completa.
7. Desde el listado puedes volver a abrirla con **Ver ficha**.
